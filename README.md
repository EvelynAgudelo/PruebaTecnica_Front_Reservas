ReservasApp - Gestión de Reservas para Restaurante

Aplicación web desarrollada con React.js para la gestión de reservas de mesas en un restaurante.  
Permite registrar, editar, finalizar y eliminar reservas de clientes de manera rápida y organizada.

Funcionalidades

Inicio de sesión con persistencia en LocalStorage  
Protección de rutas privadas  
Dashboard de reservas  
Crear nuevas reservas  
Editar reservas  
Finalizar reservas  
Eliminar reservas con confirmación usando SweetAlert2  
Estados de reservas:
Confirmada
En Espera
Finalizada

Tecnologias usadas

React.js
Vite
React Router DOM
Tailwind CSS
SweetAlert2
LocalStorage
JavaScript
